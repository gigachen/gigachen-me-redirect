# gigachen.me

Francis Gunadi's portfolio, published with GitHub Pages from `main` at the repository root.

The homepage, separated chapters, animated transitions, project pages, and Word CV are generated from the `portfolio-site/chapter_scroll/` source in the local workspace using `build_chapter_scroll.py`.

Former `/chapter-scroll/` URLs redirect to the main site. Keep `CNAME` and `.nojekyll` when publishing.
